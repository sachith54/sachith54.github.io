👋 What Is servers?

📖 Using servers Day to Day

Once the application is open, the main window lists the servers available to you. Each one has a short name and a simple switch or button beside it. Turning one on makes it available to the programs that want to use it; turning it off makes it stop.

🛟 Troubleshooting

Most hiccups have a simple fix. Work through the list below before assuming something is broken.

The download did not start.

Go back to the releases page and try again. Sometimes a browser blocks a download until you confirm it. Look for a small banner in the address bar and allow the file.

Windows shows a warning when I open the file.

This is a standard safety message for software downloaded from the internet. Choose the option to continue running it. Only ever do this for files you got from the official releases page linked on this page.

Nothing happens when I double-click.

Right-click the file and choose the option to run it as administrator. If that still does nothing, delete the file, return to the releases page, and download it again — the first copy may have been incomplete.

The application opens and then closes.

Restart your computer and try once more. Also check that you have enough free disk space, since a full drive can stop programs from starting properly.

My other program cannot find servers.

Make sure the servers window is still open and visible in your taskbar. A closed application cannot answer requests. Then look through that other program's settings for a refresh or reconnect button.

I want to start over.

Close the application, find its folder, and remove it. Then go back to the releases page and download a fresh copy. The download page always has the newest version.
